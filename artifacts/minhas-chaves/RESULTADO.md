# Minhas chaves — validação

Build aprovado. 163 testes de lógica e API aprovados; interfaces de chaves e mobile aprovadas.

Docente recebe somente suas atribuições, com próximas retiradas e chaves em uso. A gestão mantém a tela Controle de chaves. A lista pessoal não contém resumo geral, cadastro, alocação ou filtro de data. QR code e assinatura aparecem no fluxo de retirada/devolução. Retirada de alocação futura continua bloqueada pelo servidor.

Testes cobrem lista futura pessoal sem vazamento para outro docente, QR real por link/foto, assinatura, retirada, devolução, comprovantes, foco, celular, temas e acessibilidade. Dados fictícios em bancos locais temporários; nenhuma publicação realizada.
